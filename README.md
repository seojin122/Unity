# 🎮 Unity Game Collection

Unity로 만든 미니 프로젝트 모음 레포입니다.  
각 **브랜치가 하나의 완성 프로젝트**를 가리키며, 필요한 브랜치를 체크아웃해서 바로 실행할 수 있습니다.

> **브랜치 구성(업로드 순서)**  
> `Balance` → `Block` → `Maze` → `Character` → `Time` → `Final`

---

## 🚀 빠른 시작

```bash
# 1) 레포 클론
git clone https://github.com/seojin122/Unity.git
cd Unity

# 2) 브랜치 목록 확인
git branch -r

# 3) 원하는 게임 브랜치로 전환(예: Balance)
git checkout Balance
